# LovrWindowTools

Lua言語用の3Dゲームフレームワークの「<a href="https://lovr.org/" target="_blank">LÖVR</a>」で作成されたウィンドウを色々いじるためのライブラリです。
<hr>
This is a library for manipulating windows created with "<a href="https://lovr.org/" target="_blank">LÖVR</a>", a 3D game framework for the Lua language.

<hr>
<hr>

# 使用例 / Examples of Use

「conf.lua」ファイルにて、アプリケーション起動時にウィンドウを開かない設定にしている場合は、ウィンドウを開いてから各関数を実行してください。
<hr>
If you have configured the "conf.lua" file so that the window does not open when the application starts, please open the window before executing each function.

<hr>

```lua:main.lua
LovrWindowTools=require("LovrWindowTools")

function lovr.load()
    LovrWindowTools.fakeFullscreen(true)
end
```

## fakeFullscreen(p_bool,p_monitor_id)

* **p_bool**<hr>
この値をtrueにすると「フェイクフルスクリーンモード」に切り替え、falseにするとウィンドウモードに切り替えます。<hr>
Setting this value to true switches to "fake full-screen mode", while setting it to false switches to windowed mode.

* **p_monitor_id**<hr>
モニターの識別番号。1以上の値を入力してください。値がnilだと値が1に書き換わります。<hr>
Monitor ID. Please enter a value of 1 or higher. If the value is nil, it will be set to 1.

<hr>

「フェイクフルスクリーンモード」に切り替えるかの設定を行います。この関数は、Windows OSをインストールした一部の環境で「LÖVR」の通常の「フルスクリーンモード」に切り替えると「LÖVR」がフリーズしてしまう問題の対策のために作られました。「フェイクフルスクリーンモード」に切り替えると、引数p_monitor_idで指定したモニターの画面のサイズの「フェイクウィンドウ」も同時に作成され、その「フェイクウィンドウ」の中に「LÖVR」のウィンドウを入れることでフリーズを回避しています。Windows OS以外の環境では「フェイクウィンドウ」は作成されません。
<hr>
This setting determines whether to switch to "Fake Fullscreen Mode". This function was created to address an issue where "LÖVR" would freeze when switching to its standard "Fullscreen Mode" in certain environments running Windows OS. When you switch to "Fake Full-Screen Mode," a "fake window" matching the screen size of the monitor specified by the p_monitor_id argument is created simultaneously. By placing the "LÖVR" window inside this "fake window", the freeze is prevented. In environments other than Windows OS, the "fake window" is not created.
